# Ingeniería de Sistemas Journal

Repositorio académico de Ingeniería de Sistemas con materiales, apuntes,
prácticas, proyectos y recursos de apoyo para estudiantes.

## Organización

El contenido está distribuido en los diez semestres del Plan de Estudios N.º 9.
Cada materia tiene la siguiente estructura:

```text
CODIGO-nombre-de-la-materia/
├── apuntes/
├── practicas/
├── proyectos/
└── recursos/
```

- **Apuntes:** resúmenes, conceptos y notas de clase.
- **Prácticas:** ejercicios, laboratorios y soluciones.
- **Proyectos:** trabajos individuales o grupales.
- **Recursos:** bibliografía, enlaces y material complementario.

## Cómo colaborar

1. Ubica el semestre y la materia correspondiente.
2. Guarda el material en la subcarpeta adecuada.
3. Usa nombres de archivo descriptivos y evita subir datos personales.
4. No publiques libros, diapositivas u otros materiales protegidos sin permiso.

> Este repositorio tiene fines educativos y no reemplaza los materiales ni las
> instrucciones oficiales de cada docente.
